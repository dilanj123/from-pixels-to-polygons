# From Pixels to Polygons

Fixed-function FPGA 3D graphics accelerator.

This repository is at Phase 0 bootstrap. It contains the project contract,
development-environment diagnostics, and the planned repository skeleton. No
graphics implementation has been added.

The admitted `from-rtl-to-pixels` dependency is recorded in
`docs/PROJECT_STATE.md` and `docs/EVIDENCE_INDEX.md`; its production RTL is
not copied into this repository during GFX-000.

Run:

```text
make doctor
```

to inspect the local environment without modifying it.
